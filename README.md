# kalashnikova-pravo
Сайт Правового кабинета Екатерины Калашниковой

## Страницы услуг

Тексты и цены находятся в `tools/services.json`, общий шаблон — в `tools/service-page.html`.
Чтобы добавить страницу SEO-3, внесите услугу с уникальным адресом и ссылками на связанные услуги, затем выполните `python3 tools/render_services.py`. Команда обновит статические страницы и добавит новые адреса в sitemap.xml. Для входа с главной добавьте ссылку в нужную карточку или строку прайса и сверьте начальную цену.
